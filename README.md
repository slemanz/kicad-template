# Kicad Template

### Setup Instructions

To use this template in KiCad, follow these steps:

1. **Import the Worksheet File:** Go to **File > Page Settings** and select the
`.kicad_wks` file in the **Page Layout Description File** field.

2. **Configure Page Variables:** In the same **Page Settings** window, fill in
the following fields:

- **Issue Date:** Initial project date.
- **Revision:** The current project revision/version.
- **Title:** The project title.
- **Company:** company or organization name.
- **Comment 1:** `"For more designs, visit"`
- **Comment 2:** Your website or portfolio URL.
- **Comment 3:** Company URL.


3. **Add Text Variables:** Navigate to **Schematic Setup > Text Variables** and
add the following:

- **DESIGNER**
- **VARIANT**
- **YEAR**
